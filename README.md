# NitroKill

تطبيق أندرويد (Kotlin + Jetpack Compose) يجمع بين:
1. مؤشر واضح وبارز لسرعة الإنترنت في شريط الإشعارات (بجوار البطارية/الساعة)
2. ميزة إغلاق التطبيقات العاملة في الخلفية عبر خدمة Accessibility

## طريقة البناء (GitHub Actions)

1. أنشئ مستودع جديد على GitHub وارفع محتويات هذا المجلد كما هي.
2. تأكد أن الفرع الرئيسي اسمه `main` (أو عدّل اسم الفرع في `.github/workflows/android-build.yml`).
3. كل push على `main` يشغّل البناء تلقائياً (أو شغّله يدوياً من تبويب Actions → Build NitroKill APK → Run workflow).
4. بعد اكتمال البناء، ستجد ملفي APK (debug و release غير موقّع) تحت تبويب **Artifacts** في صفحة الـ run.
5. الإصدار release غير موقّع — قبل رفعه لمتجر بلاي لازم توقّعه بمفتاحك الخاص (keystore)، هذا الجزء لم يُضف للـ workflow لأنه يتطلب منك رفع مفتاح توقيع سرّي (GitHub Secrets)؛ أخبرني إذا تبي أضيف هذي الخطوة لاحقاً.

لا يحتاج المشروع Gradle wrapper محلي — الـ workflow يثبّت Gradle وAndroid SDK بنفسه، فما تحتاج شي مثبت على جهازك غير رفع الملفات على GitHub.

## الأذونات اللي المستخدم لازم يفعّلها يدوياً بعد التثبيت

| الإذن | لماذا | من وين |
|---|---|---|
| الإشعارات | لعرض مؤشر السرعة | يُطلب تلقائياً عند أول فتح (أندرويد 13+) |
| Accessibility (خدمة NitroKill) | لتفعيل زر "إعادة تمكين" (إغلاق التطبيقات فعلياً) | من داخل التطبيق: خيارات → تفعيل بجانب "خدمة إغلاق التطبيقات" |
| الوصول لبيانات الاستخدام | اختياري، لتحسين دقة جدول الاستهلاك مستقبلاً | من داخل التطبيق: خيارات |

## كيف عالجت كل متطلب من ملاحظاتك

- **المؤشر بارز وواضح**: بدل أيقونة إشعار ثابتة، الرقم نفسه يُرسم كصورة (bitmap) ويصير هو أيقونة الإشعار (`util/IconTextGenerator.kt`) — نفس الأسلوب المستخدم في تطبيقات قياس السرعة المعروفة. هذا يحل مشكلة "الأيقونة صغيرة" اللي واجهتها بالنسخة السابقة.
- **زر بثلاث خيارات (خيارات / إعادة تمكين / إخفاء وخروج)**: قائمة منسدلة (⋮) أعلى الشاشة الرئيسية.
- **إخفاء زر الخروج**: ما فيه زر "إغلاق" مباشر على الشاشة الرئيسية أصلاً؛ الخروج الوحيد المتاح هو "إخفاء وخروج" داخل القائمة، وهو يُصغّر التطبيق (`moveTaskToBack`) بدون ما يوقف خدمة المراقبة.
- **إغلاق التطبيقات فعلياً**: عبر `CleanerAccessibilityService` — يفتح شاشة "التطبيقات الأخيرة" ويضغط زر "مسح الكل" تلقائياً (أو يغلق كل بطاقة على حدة إذا ما فيه هذا الزر). **قيد مهم موثّق بالتفصيل داخل الكود**: هذا الأسلوب يعتمد على واجهة "التطبيقات الأخيرة" الخاصة بكل شركة (سامسونج/شاومي/ستوك أندرويد تختلف), فهو الأفضل الممكن بدون روت وليس مضموناً ١٠٠٪ على كل جهاز — يحتاج اختبار على الأجهزة المستهدفة فعلياً وربما تعديل بسيط حسب الجهاز.
- **جدول الاستهلاك (تاريخ/جوال/انتقال/المجموع)**: `data/UsageRepository.kt`، يُصفّر تلقائياً كل يوم جديد. ملاحظة: هذا تقدير تقريبي مبني على `TrafficStats` وليس عداد شركة الاتصالات، ولهذا بالضبط وضعنا نص التنويه اللي طلبته.
- **اللغة (عربي/إنجليزي)**: تبديل فوري داخل الخيارات، `util/LocaleHelper.kt`.
- **حجم التطبيق**: لا مكتبات ثقيلة — Compose الأساسي فقط + DataStore بسيط، بدون `material-icons-extended` (وحدها تضيف عدة ميجابايت)، و R8/ProGuard مفعّل بالنسخة release لتصغير الحجم تلقائياً.
- **تغيير لون المؤشر**: ألوان الأيقونة المولّدة بيضاء ثابتة حالياً (أوضح تباين على شريط الإشعارات الأسود) — لو تبي إضافة خيار لتغيير لونها من شاشة الخيارات أقدر أضيفه، هذا يحتاج نقاش بسيط لأن أندرويد يفرض تلوين رمادي/أبيض لأيقونات الإشعارات في أغلب الإصدارات (تلوين حر غير مضمون على كل نظام).
- **أحدث إصدار أندرويد**: `compileSdk`/`targetSdk = 36` (Android 16) — هذا صار إلزامي لأي تطبيق جديد يُنشر على بلاي ابتداءً من ٣١ أغسطس ٢٠٢٦.
- **البريد والمطور**: مكتوبين داخل "حول" (`saleh.mabkhot@hotmail.com`، `@iSx3i`).
